# A3. Ranked (variant of A)

- **Idea:** the % leads each row on the left, and a faint gold fill behind each row is as wide as its chance to win, so the list reads as a set of bars.
- **Moving around:** as A (top bar, word tabs showing each category's leader).
- **Density:** airy; each contender on its own white row with a hairline outline; the "why" opens under the row.
- **Type:** Hanken Grotesk (300–700).
- **Colour:** warm white (#FCFBF8), a gold fill at 9% strength with a solid gold edge.
