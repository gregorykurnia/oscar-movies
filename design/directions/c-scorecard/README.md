# C. Scorecard

- **Idea:** the race as a precise table. Each film's precursor run is drawn as a strip of small cells (solid gold = won, outlined = nominated, hatched = still to come), so the season's shape reads across the rows.
- **Moving around:** top bar with sections and a wide search (`/`). A left rail lists the four categories with their stage and leader; the chosen one fills the table. Phone: the rail becomes cards that scroll sideways; the table becomes rows, with the precursor results as text.
- **Density:** dense but calm. Eight films and an open "why" on one desktop screen; columns for average, % to be nominated and % to win.
- **Type:** Instrument Sans (400–700). Compact, slightly narrow; tabular figures.
- **Colour:** pure white with a warm grey rail (#F8F7F4); Oscar gold only in the cells, the bars and the leader's %.
- **Shows:** Best Picture, 2025 race as of 20 Dec 2025 (real films, illustrative %), with the "why" open on Hamnet.
